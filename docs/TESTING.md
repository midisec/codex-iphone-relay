默认检查不使用真实 API。集成测试使用 localhost TCP；不能替代蓝牙、USB、后台或锁屏真机测试。

## 真机验收

两端配对并开始转发后执行。测速仅做数据回传，追问脚本会调用真实 API。

```bash
# 蓝牙回传与追问
python3 scripts/benchmark_bluetooth.py --transport bluetooth
python3 scripts/verify_followups.py --transport bluetooth

# Type-C 回传与追问
python3 scripts/benchmark_bluetooth.py --transport usb --size-kib 4096
python3 scripts/verify_followups.py --transport usb
```

测速使用随机字节和可压缩文本，校验 SHA-256。同时记录上传、下载吞吐、协议版本和蓝牙写入耗时。记录时需注明数据量、耗时、连接方式、系统版本以及 App 是否在前台。有效吞吐计算为往返应用数据总量除以总耗时。

将一次独立 API 请求的文字增量追加到文件：

```bash
python3 scripts/stream_to_file.py '请写三段简短文字' --output output/response.txt
```

## 已记录结果

测试环境：Apple Silicon Mac、macOS 15.3.1、iOS 26.6.1，协议 v2。结果反映当时设备与网络条件，不是所有平台的性能保证。

| 检查 | 结果 |
| --- | --- |
| 蓝牙 + API 并发 | 256 KiB 随机数据，约 19.6–23.8 KiB/s，SHA-256 一致 |
| Type-C 前台回传 | 每轮上传及下载各 4 MiB，约 20.5–21.7 MiB/s，SHA-256 一致 |
| 关闭 USB 网络共享后回传 | 同样 4 MiB 往返，约 7.18 MiB/s |
| 其他有线运行条件 | 最低记录约 4.71 MiB/s；该轮未可靠确认全程锁屏，不算锁屏验收 |
| 蓝牙前台、短时后台 | 无数据线三轮追问完成，保留上下文 |
| Type-C 前台 | 三轮追问完成，SSE 文字增量实时返回 |
| v1.3 Mac 界面 | 三模式启停与实际服务一致，弹窗和窗口重开通过 |
| v1.3 iPhone | 构建、签名、安装及界面检查通过 |
| v1.4 API 编辑 | 32 项配置检查通过；实际 UI 验证地址校验、取消、保存及测试通道重连 |

真实 Codex 追问测试对测试进程禁用外部网络，只允许 localhost；没有关闭整台 Mac 的网络。

## v1.5 复测

2026-09-28，协议 v3，iPhone 前台。Mac 使用纯蓝牙，数据线仍连接，USB 网络共享禁用。每轮上传及回传各 256 KiB。

| 样本 | 有效吞吐 | 校验 |
| --- | --- | --- |
| 随机数据，16 KiB 写入上限 | 21.6 KiB/s | SHA-256 一致 |
| 随机数据，4 KiB 写入上限 | 22.1 KiB/s | SHA-256 一致 |
| 随机数据，64 KiB 写入上限 | 23.7 KiB/s | SHA-256 一致 |
| 项目源码文本，3 轮 | 76.0–88.6 KiB/s | SHA-256 一致 |

代码文本压缩后约为原数据的 28%，不能把有效吞吐当成蓝牙物理速率。三种写入上限各测一轮，没有证明调整上限有稳定增益，默认仍为 16 KiB。随机数据的 Mac 写入调用累计约 3.6–5.4 ms，单轮往返约 21.6–23.7 s。

[原始数值](benchmarks/2026-09-28-bluetooth.json)

- 纯蓝牙三轮 Codex 追问完成，保留上下文，均收到 `turn.completed`；测试进程禁止外网，只允许 localhost。
- 最终构建补测：默认 16 KiB 写入上限，128 KiB 随机往返 27.1 KiB/s，SHA-256 一致；样本大小不同，不作为提速对照。
- 两端配置握手同步通过；Mac 界面切换来源后收到手机保存确认，恢复为自动。
- Mac 界面验证缺失来源报错、有效来源保存和密钥留空保留。
- 50 项核心、9 项 USB、34 项 API 编辑、36 项配置同步、4 项安装器检查及 TCP 集成测试通过。
- 更早的一次测速在手机离开前台后中断，随后自动重连；不计入上述前台样本，后台长期稳定性仍待验证。

v1.5.1 的链路参数、时序及调度对照见 [蓝牙链路诊断](BLUETOOTH_DIAGNOSTICS.md)。
