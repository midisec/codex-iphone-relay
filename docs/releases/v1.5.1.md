## 发布文件

| 文件 | 内容 |
| --- | --- |
| `codex-relay-v1.5.1-macos-arm64.zip` | Apple Silicon Mac 安装器、运行环境、iPhone 签名工具 |
| `codex-relay-v1.5.1-ios-unsigned.ipa` | iPhone 预编译 App，需个人签名 |
| `codex-relay-v1.5.1-source.zip` | 源码、安装脚本、截图、使用教程 |
| `SHA256SUMS` | 三个发布包的校验值 |

系统要求：Apple Silicon Mac、macOS 13+、iOS 16+。Mac 包不含 Codex 桌面 App；需自行安装并准备 Responses API 配置。

```bash
LC_ALL=C shasum -a 256 -c SHA256SUMS
```

Mac 解压后双击 **Install.command**，无需 Python 或 Xcode。IPA 导入 **AltStore Classic**，或使用包内 **Sign-iPhone.command** 配合自己的证书签名。签名有有效期；此 Mac 包未经过 Apple 公证。

详细步骤：[免编译安装](../BINARY_INSTALL.md) · [配对与使用](../USAGE.md)。

## 已有用户更新

等待当前请求结束，退出 Mac 转发 App，运行新包的 **Install.command**。手机使用原签名账号和 Bundle ID 覆盖安装新 IPA。

安装器保留配对密钥，但会重新导入 `--source` 的 API。更新后打开手机 App，点击 **开始转发**，确认 API 来源和 **已同步** 状态。
